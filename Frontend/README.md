# Frontend - Therapy Internship

Frontend i projektit eshte ndertuar me React dhe Vite.

## Kerkesa

- Node.js 18+
- npm

## Instalimi dhe nisja

```bash
npm install
npm run dev
```

Pas nisjes, aplikacioni eshte i disponueshem ne `http://localhost:5173`.

## Rrugat kryesore

- `/` - Home
- `/login` - Login
- `/signup` - Signup
- `/dashboard` - Dashboard
- `/register` - Register

## Skriptat

- `npm run dev` - Start development server
- `npm run build` - Build production bundle
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint checks
